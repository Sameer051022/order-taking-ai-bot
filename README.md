# 🍗 AI Ordering Agent — WhatsApp-First Restaurant Ordering Bot

[![Node](https://img.shields.io/badge/Node-22%2B-green?logo=node.js)](https://nodejs.org)
[![TypeScript](https://img.shields.io/badge/TypeScript-blue?logo=typescript)](https://www.typescriptlang.org)
[![Fastify](https://img.shields.io/badge/Fastify-black?logo=fastify)](https://fastify.dev)
[![Claude](https://img.shields.io/badge/Powered%20by-Claude-orange)](https://www.anthropic.com)

An enterprise-shaped, WhatsApp-first AI ordering agent for restaurants. Claude is the conversation layer only — this backend is authoritative for the menu, pricing, deals, promotions, branches, availability, delivery quotes, orders, and order status.

`Customer → WhatsApp → AI agent (Claude + tools) → Order engine → Branch / Cart / Pricing / Promotions → POS / KDS`

Built by the team at [Kodevengers](https://kodevengers.com). I worked on this as a Full Stack & AI Automation Engineer at Kodevengers, building out the order engine, agent tooling, and demo/presentation layer.

---

## ✨ Features

| Area | Notes |
|---|---|
| 🍽️ Menu model | Categories → products (item/deal) → modifier groups (min/max/repeat) → modifiers, with per-branch availability |
| 🛒 Cart engine | Server-side and deterministic; merges identical configs, splits units, resolves option names fuzzily ("no mayo", "large") |
| 💵 Pricing | subtotal → promo discount → tax → delivery fee → total, all integer math |
| 🎟️ Promotions | Percent / fixed / free delivery, min order, max discount, product/category/branch scope, per-customer limits — eligibility is never decided by the LLM |
| 📍 Branch routing | Typed area or WhatsApp location pin → nearest open branch in radius → zone fee + ETA |
| 📦 Orders | Snapshot of items/totals with a full status machine (Confirmed → Preparing → Ready → Rider assigned → On the way → Delivered), each step pushed to the customer over WhatsApp |
| ⬆️ Upsell | Rule-based product + pitch offered once per conversation, tracked for analytics |
| 📊 Analytics | Orders, revenue, AOV, conversion, abandoned carts, upsell acceptance, peak hours, AI response time |
| 🤖 Agent | Claude Opus, manual tool-use loop with 21 tools wrapping the engine, Roman-Urdu tolerant |
| 💬 Channels | WhatsApp Cloud API webhook + a browser-based simulator for demos without a Meta account |
| 🖥️ Dashboard | Live order board, conversations with human takeover, menu/branch controls |

## 🏗️ Tech Stack

- **Runtime:** Node.js 22+, TypeScript
- - **Server:** Fastify
  - - **Database:** better-sqlite3 (swappable for Postgres — every query goes through `src/core/*`)
    - - **AI:** Anthropic Claude (Opus), via `@anthropic-ai/sdk`
      - - **Channels:** WhatsApp Cloud API
        - - **Demo tooling:** Playwright + ffmpeg for automated demo-video recording

          - ## 🚀 Getting Started
         
          - ```bash
            cp .env.example .env   # add your ANTHROPIC_API_KEY
            npm install
            npm run dev             # seeds demo data on first start
            ```

            - Client presentation: `http://localhost:3000/presentation/`
            - - WhatsApp simulator: `http://localhost:3000/demo/`
              - - Restaurant dashboard: `http://localhost:3000/dashboard/`
               
                - Without an API key, the backend, dashboard, and simulator still run — the agent just replies that it isn't configured yet.
               
                - ## 🎬 Demo Modes
               
                - - **Scripted demo** — pre-written customer/agent lines, but every tool call runs on the real order engine, so cart, pricing, promos, and orders are all live. Never depends on a model call, so it can't fail mid-pitch.
                  - - **Live AI** — everything generated by Claude, for letting a client type their own order.
                   
                    - A demo video can be recorded end-to-end with Playwright + ffmpeg via `npm run record`.
                   
                    - ## 🔧 Configuration
                   
                    - | Variable | Default | Purpose |
                    - |---|---|---|
                    - | `ANTHROPIC_API_KEY` | — | Claude credentials |
                    - | `AGENT_MODEL` | `claude-opus-5` | Model id |
                    - | `PORT` | `3000` | HTTP port |
                    - | `DATABASE_PATH` | `./data/app.db` | SQLite file |
                    - | `WHATSAPP_*` | — | Cloud API access token, verify token, Graph version |
                   
                    - ## ✅ Verification
                   
                    - ```bash
                      npm test        # engine + tool-layer tests, no API key needed
                      npm run typecheck
                      npm run eval     # live scripted conversations against the real agent
                      ```

                      ## 📈 Going to Production

                      - **Database:** swap SQLite for Postgres without touching the agent — every query is behind `src/core/*`
                      - - **Geocoding:** replace `geocode()` in `src/core/branches.ts` with Google/Mapbox
                        - - **POS / KDS:** subscribe to `order.created` on the event bus and push to the chain's ordering API
                          - - **Payments:** `place_order` accepts `cash | card`; add an online method for a payment link
